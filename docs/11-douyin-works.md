# 11 · 博主作品搜索与下载

## 页面与边界

- “内容 → 博主搜索下载”（`/douyin-download`）负责搜索、筛选和提交下载；成功转存到 OSS 的作品展示在[博主详情](10-douyin-creators.md) `/douyin-creators/:id` 的资料区下方，与[视频库](03-videos.md)独立，不再设立单独的作品页面或侧栏入口。
- 搜索支持选择[已有博主](10-douyin-creators.md)，或输入主页 URL、分享短链、`sec_uid`。已有身份直接复用；新博主先完成资料入库，再查询作品。页面提示资料采集和作品查询可能分别产生费用。
- 搜索不自动下载；支持单条及当前页勾选批量下载。下载指保存到系统 OSS，不提供图文下载、导出、打包下载或转写等能力。
- 详情页的作品列表固定为当前博主，不提供跨博主切换；保留分页、标题搜索、播放、原页链接和确认删除。列表沿用视频库的紧凑卡片：每行随屏幕宽度显示 2～6 张，3:4 缩略区铺满裁切，底部渐变层展示互动数，下方展示两行标题、作者和发布日期；原页链接与删除放在右上角操作菜单。播放弹窗保留 9:16 竖屏画框，完整展示视频、不裁切，并随视口高度限制尺寸。封面尽力转存，失败时加载视频首帧；删除作品清理其 OSS 视频和封面，并刷新详情中的下载数。

## 搜索、筛选与记录

- 通过 `guaikai-api-service` 的博主作品异步接口获取数据；上游 `url` 使用规范化 `sec_uid`，`limit` 为已入库作品数，最多 10000。作品数为零不请求作品接口；不会自动付费刷新旧资料。
- 当前用户至多一个进行中的搜索，包含等待新博主入库阶段；后端用户行锁保证跨标签页限制，其他用户不受影响。后台轮询最多等待 30 分钟；提交前持久化上游时间戳，网络异常和重新搜索不会自动重建已提交的付费任务。
- 后端取得结果后按发布时间范围、点赞/收藏/评论下限取 AND 筛选，发布时间倒序、本地分页。日期使用北京时间自然日，包含起止日期；缺失互动数按 0，缺失发布时间不匹配日期筛选。
- 无视频链接或作品 ID 的条目不可下载；列表区分符合条件数量、可下载数量及已下载状态。调整当前结果的条件只筛选缓存，不调用上游，不覆盖原搜索条件。
- 搜索记录弹窗按当前用户分页保存摘要：博主、来源、时间、条件、状态、获取/匹配数量、失败原因及缓存版本。不持久化全量结果或匹配快照。
- 搜索记录的操作按钮位于每条记录右侧状态下方，摘要文字超出可用宽度时单行省略。“查看结果”打开第二个只读列表弹窗，用对应缓存版本和原条件还原；没有下载或筛选操作。缓存过期或失效后只保留摘要，不能查看结果；不使用新版本替代历史数据。

## 七天共享缓存

- 仅作品查询启用缓存，不改变博主资料 `limit=0` 的新增和刷新语义。缓存键为接口、规范化博主身份与 `limit` 的摘要，不含用户、本地筛选条件和时间戳。
- 原始公开数据全局共享，同参数进行中查询合并；用户的博主、搜索、作品和下载任务仍独立。成功结果（包括合法空列表）从取得结果起缓存七天，失败不缓存、读取不续期。
- 缓存到期立即逻辑失效；搜索记录查询及每小时清理任务移除过期结果内容。页面显示获取与到期时间。
- “使缓存失效”需要确认，全局失效该搜索引用的缓存版本，但不立即查询、不删除历史；旧记录不能清除新版本，上游查询进行中不能失效。下次新建上游任务可能产生费用。

## 后台下载

- 搜索下载页及博主详情页均提供下载任务弹窗，按用户、批次分页展示数量、进度、单条状态和失败原因。关闭弹窗或离开页面不停止任务，可单条重试或重试本批失败项；不提供取消和独立删除任务历史，关联记录随博主删除一并清理。
- 按用户与作品 ID 去重；成功作品不重复下载，进行中复用任务，失败可重试。不同用户各自拥有 OSS 文件，不跨用户复用。
- 提交时只保存选中作品的必要下载元数据，任务不依赖原搜索缓存继续存在。按 `video_url` 顺序尝试，逐一完整下载到临时文件后上传 OSS，全部失败则失败；不自动重新付费获取直链。缓存有效不保证直链有效，重试仍可能失败。
- 下载仅接收已知抖音媒体域名，重定向逐跳校验；限制单次资源读取时间、视频大小 1 GiB、封面大小 20 MiB。单条任务执行最多 20 分钟，队列等待超时也可手动重试；重试不产生新的作品查询费用。
- 通过执行令牌防止过期 worker 回写重试任务；视频转存和作品持久化成功后才标记完成。失败清理本次已上传对象及临时文件。
- 删除博主需确认，同时删除当前用户关联的全部作品、下载批次/任务、搜索记录（含等待资料入库的搜索）及资料采集任务，不再因进行中任务阻止删除。共享的公开作品缓存保留，不影响其他用户。
- 删除先清理已保存作品的 OSS 视频及封面，再在同一数据库事务中删除业务记录；OSS 清理失败则报错并保留记录供重试，已删除的部分文件无法随数据库回滚恢复。删除与任务创建、作品入库使用同一用户锁；遗留队列消息遇到已删除记录即不再执行，已在途的外部请求无法撤回，下载 worker 回写失败时清理本轮已上传文件。

## 实现与运行

- 后端：`douyin-posts-controller.ts`、`douyin-post-service.ts`、`douyin-download-service.ts`、`utils/douyin-post.ts`，以及 `douyin-post-job.ts` / `douyin-download-job.ts`。
- 数据：`DouyinPostCache`、`DouyinPostSearch`、`DouyinDownloadBatch`、`DouyinDownloadTask`、`DouyinWork`；模型继承迁移生成的 schema，不手工维护生成文件。
- 前端：`apps/web/src/features/douyin-post/`（搜索和任务弹窗）、`apps/web/src/features/douyin-creator/detail-page.tsx`（详情与已下载作品），以及 `_auth/douyin-download`、`_auth/douyin-creators/$id` 路由。
- 接口统一在 `/api/v1` 下：`/douyin-post-searches`（创建、历史、状态、结果、失效）、`/douyin-downloads`（提交、批次、明细、重试）、`/douyin-works`（列表、删除）。
- `pnpm --filter api start:queue-worker` 包含 `douyin-post-queue`、`douyin-download-queue`。Redis 模式由 API 注册每小时缓存清理计划；API、Redis 和 worker 需分别运行。
- 上线前由维护者执行新增迁移并生成 schema，再生成 API 客户端和检查类型；Agent 不执行数据库操作，见 [09](09-development.md)。
